# BookShelf Scanner

JANコード/ISBNをスキャンして、読書記録をObsidianに保存するPWAアプリです。

## 機能

- 📷 カメラでJANコード/ISBNバーコードをスキャン
- 📚 openBD API / Google Books APIで書籍情報を自動取得
- 🖼️ 表紙画像も自動取得
- ⭐ 5段階評価
- 📅 読了日記録
- 📝 メモ欄
- 📲 Obsidianに直接保存（1ファイルに追記形式）

## セットアップ

### 1. Obsidianプラグインのインストール

このアプリは **Advanced URI** プラグインを使用してObsidianにデータを送信します。

1. Obsidianを開く
2. 設定 → コミュニティプラグイン → 閲覧
3. **Advanced URI** を検索してインストール
4. プラグインを有効化

### 2. アプリの設定

1. アプリの「設定」タブを開く
2. **Vault名**: ObsidianのVault名を入力（例: `MyVault`）
3. **保存フォルダ**: 読書記録を保存するフォルダ（例: `Books`）
4. **ファイル名**: リストファイル名（例: `読書記録`）

### 3. ホーム画面に追加（PWA）

スマートフォンでアプリとして使用するには：

**iOS (Safari)**:
1. Safariでアプリを開く
2. 共有ボタン → 「ホーム画面に追加」

**Android (Chrome)**:
1. Chromeでアプリを開く
2. メニュー → 「ホーム画面に追加」

## 使い方

1. 「スキャン開始」をタップしてカメラを起動
2. 本のJANコード（バーコード）をかざす
3. 自動で書籍情報が表示される
4. 評価、読了日、メモを入力
5. 「Obsidianに保存」をタップ
6. Obsidianが開き、読書記録が追記される

## 保存されるMarkdown形式

```markdown
---

## 本のタイトル

![表紙](https://example.com/cover.jpg)

- **著者**: 著者名
- **ISBN**: 9784000000000
- **読了日**: 2025-01-12
- **評価**: ★★★★☆

### メモ
ここにメモが入ります
```

## ホスティング

このアプリを使用するには、HTTPSでホスティングする必要があります（カメラアクセスに必要）。

### 簡単な方法

1. **GitHub Pages**: リポジトリにプッシュして Pages を有効化
2. **Netlify**: ドラッグ&ドロップでデプロイ
3. **Vercel**: GitHubと連携してデプロイ

### ローカルテスト

```bash
# Python 3
python -m http.server 8000

# Node.js
npx serve
```

※ローカルテストではHTTPSではないため、カメラが動作しない場合があります。
その場合は手動でISBNを入力してテストしてください。

## API

- **openBD**: 日本の書籍情報API（無料、登録不要）
- **Google Books API**: フォールバック用（レート制限あり）

## 注意事項

- Obsidian URIスキームはデスクトップ版・モバイル版の両方で動作します
- Advanced URIプラグインが必要です
- 表紙画像はURLとして保存されます（ローカルにはダウンロードされません）
